# Учебная платформа

Платформа для управления домашними заданиями — преподаватель создаёт задания (тесты или текстовые), студенты их выполняют, преподаватель проверяет и выставляет оценки.

## Технологии

- **Next.js 14** (App Router)
- **Prisma** + SQLite
- **NextAuth.js v4** (вход по телефону + пароль)
- **Tailwind CSS**
- **TypeScript**

---

## Установка и запуск

### 1. Установить зависимости

```bash
npm install
```

### 2. Настроить базу данных и заполнить тестовыми данными

```bash
npm run setup
```

Эта команда выполняет миграцию базы данных и создаёт тестовые аккаунты.

### 3. Запустить приложение

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## Функциональность

### Преподаватель
- Создание заданий двух типов:
  - **Тест** — вопросы с вариантами ответов (2–5 вариантов, один правильный)
  - **Текст** — свободный текстовый ответ
- Просмотр статистики по каждому заданию
- Просмотр работ студентов
- Выставление оценок (0–100) с комментарием

### Студент
- Просмотр списка всех заданий со статусами и дедлайнами
- Выполнение тестов (радио-кнопки)
- Написание текстовых ответов
- Просмотр своих результатов и комментариев преподавателя
- Защита от повторной сдачи

## Добавление студентов

### Через Prisma Studio

```bash
npx prisma studio
```

Откроется веб-интерфейс по адресу `http://localhost:5555`. Перейдите в таблицу `User` и добавьте новых пользователей с ролью `STUDENT`.

**Важно**: пароль нужно хешировать bcrypt перед сохранением. Используйте скрипт seed.ts для вдохновения.

### Через скрипт seed.ts

Добавьте нового студента в массив `students` в файле `prisma/seed.ts` и повторно запустите:

```bash
npm run db:seed
```

## Переменные окружения

Файл `.env` уже настроен для локальной разработки. Для продакшена обновите:

- `NEXTAUTH_SECRET` — длинная случайная строка
- `NEXTAUTH_URL` — URL вашего приложения
- `DATABASE_URL` — путь к файлу базы данных
